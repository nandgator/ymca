# Prototype — archived

This directory holds the original **YMCA Mess Management** prototype: a small
Go backend and a Kotlin/Compose Multiplatform app that digitalized one
hostel's paper mess register (see [`CONTEXT.md`](./CONTEXT.md) for its domain
glossary).

It is kept for reference only. The project has since been redirected toward
the full platform described in [`../docs/system-design/`](../docs/system-design/),
which is being built fresh — see the top-level [`README.md`](../README.md).

Nothing here is maintained. Paths in the sub-`README`s that point at
`/CONTEXT.md` now mean [`prototype/CONTEXT.md`](./CONTEXT.md).
